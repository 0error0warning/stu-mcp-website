# Detailed visual feedback · 2026-10-26

This is a historical stage. The subsequent [reference refinement](reference-refinement-2026-10-26.md) replaces its numeric calendar, Prompt terminal, labeled Dock layout and one-shot information beams. In particular, the old visible-beam idle RAF sample below does not describe the current continuous visible beam.

The retained baseline remains Side Quest Adoption Center. This revision follows
the owner's eleven browser comments and six linked component requests. It stays
private and local; no deployment or account operation was performed.

## Requested Magic UI components

- **Animated Beam:** three source nodes connect to STU-MCP and Your Agent,
  measured from real element geometry; vertical arrangement on phones.
- **Terminal:** accessible Agent/terminal tabs. Copy always uses the selected
  full text, even before typing finishes. The shell command comes from the
  public v0.7.1 installation document; no commands are executed by the site.
- **Dock:** centered, labeled, keyboard-accessible links with fixed layout slots
  and a fine-pointer spring magnification.
- **Border Beam:** a finite border pass on “一个答案，也该有来时的路。”
- **Animated Theme Toggler:** real light/dark palettes, local persistence,
  circular View Transition with direct-switch fallback and reduced-motion support.
- **Text Animate:** finite entrance for selected short product text.

Official Magic UI registry sources are pinned at
`efe76fc5755eca1142dd4f74c1d6f0ace2887e3c`; their MIT notice is retained.
The ReactDrops Component License remains intact. Provenance and local renderer
patches are described in `THIRD_PARTY_NOTICES.md`.

## Actual verification

Local Chromium through Playwright CLI, on Windows; these are browser simulations,
not real iOS/Android hardware tests. No credentials or personal information used.

- Actual page widths 1169 and 709, plus 390×844 / DPR 2 touch context: no
  horizontal overflow. Dock center error is 0 px; four links remain visible.
  Additional isolated header checks covered 1440, 981 and 980 px.
- Actual browser `FontFace` reports Noto Sans SC loaded, weights 400–700.
  The downloaded 124,708-byte font covers all 439 requested UI characters.
- Hero navigation reaches `#install` below the sticky header. An early 450 ms
  assertion caught the smooth scroll before it finished; waiting for the target
  verified its actual top at about 96 px. This was a verification timing fix.
- Actual clipboard comparisons passed for the complete Agent prompt, the
  documented wheel/setup commands, and a scenario prompt. Terminal tab arrow-key
  selection and Gallery arrow-key selection passed. FAQ expansion passed.
- During filtering, grid animation and exit ghosts were actually running.
  After rapid life/study/all changes, six cards remained, six motion regions
  were observed, and no ghosts remained. Stable phone taps returned 3 / 3 / 6
  cards. An earlier immediate tap after a synthetic flick did not apply the
  selection; the settled-page tests above verified the actual tap handler.
- Four beam paths use real nonempty coordinates; phone layout puts the Agent
  below the hub. Border offset changed during its actual finite pass.
- Theme toggle, persistence through reload, and 390px night layout passed.
  The theme uses `data-theme`, avoiding the baseline's existing `.dark` card class.
- Actual touch scrolling passed. Reduced motion has zero canvases, zero running
  DOM animations, a complete terminal prompt, and no horizontal overflow.
- Data API returned HTTP 200, `delivery: live`, 90 days and 116 commits. The
  compact 30-day/weekly views preserve the same real counts; arithmetic,
  pagination, invalid-data fallback, date and keyboard checks are documented
  in `activity-data.md`.
- No page exceptions or failed page requests in the desktop functional run;
  no phone page exceptions. Production preview loads only same-origin assets,
  the Chinese font, six scenarios and the public activity endpoint correctly.
- Production preview idle samples: after 7.5 seconds of warmup, each of the
  hero, beam, border and terminal regions had **0 JS RAF callbacks, 0 WebGL
  draw calls and 0 connected 2D clear calls** in a 1.2-second sample. This is not
  a whole-device FPS measurement; the original external SVG's native animation
  remains outside this JS counter.
- `npm run build` and 9 Node checks passed. The real canvas regression page
  passed all 7 checks with no skips: 69 actual moving frames, 16,648 moving
  pixels, 0 stale pixels and 0 alpha differences; actual WebGL buffer resize
