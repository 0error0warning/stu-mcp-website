它是一个新的聊天机器人吗？

STU-MCP 是 MCP 信息连接工具，负责检索、读取和返回有出处的信息。你继续使用自己的 Agent，由它来理解和整理。

需要 Hermes 或额外的模型 API Key 吗？

不需要先安装 Hermes，也不需要为 STU-MCP 单独配置模型 API Key。你所用 Agent 自身的模型和订阅要求，取决于该客户端。

账号密码应该在哪里输入？

本人在本地私密设置页或终端完成认证。介绍站不接收账号密码，也不要把认证信息发给 Agent。不同来源可能需要单独登录，具体按安装与认证文档操作。

为什么有时查不到，或者信息不够新？

来源权限、网络、已接入范围和缓存都会影响结果。查不到不等于没有这条信息。让 Agent 检查来源及缓存时间，需要最新信息时先刷新，重要要求以原文为准。

可以替我提交作业、付款或自动报修吗？

不要把读取信息理解成自动办事。一卡通只读，不充值或挂失。宿舍报修需完整预览、本人明确确认后才可提交；当前真实 HTTP 预览已验证，正式新提交仍待真实验收。它不支持万能自动提交。

这是官方服务吗？适用范围是什么？

这是个人独立开发的开源项目，非汕头大学官方服务。适配范围围绕仓库列出的实际来源；公开讨论也不代表官方要求。使用前请查看功能说明和验证记录。
