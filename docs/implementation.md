# Implementation direction

Visual thesis: a warm, illustrated paper workshop where scattered source material finds its way into the visitor's own Agent.

Content: product poster → six real prompts → sources/STU-MCP/your Agent → source freshness → project activity → local installation → FAQ and source links.

Interaction thesis: paper and signal motion in the hero; soft source-to-Agent paths; tactile prompt copying. Integrate a larger selection of compatible ReactDrops effects following the owner's 2026-10-26 request, preserving their license and a coherent Side Quest composition.

Baseline: Side Quest Adoption Center, retained unchanged in reference/side-quest/index.html. Product baseline: stu-mcp v0.7.1, 50 MCP tool registrations, verified from the local sibling repository on 2026-10-26. This verifies documentation and registration, not every live business operation.

2026-10-26 revision: one full-hero physics world replaces the two narrow lanes.
The visible yellow CSS ellipse supplies the actual collision geometry. Characters
fall from across the page top and roll outward under gravity. Use larger shapes
and fewer bodies (4 / 6 / up to 10), with 60% gaze following. Preserve the same
world through scrolling and backgrounding; randomize only on a fresh page load.
Normal-motion module loading never displays a pre-settled static pile.

2026-10-26 performance revision: hero characters are now opt-in and disabled
on every fresh page. The inactive gate mounts no physics scene or observers,
and never imports its engine. A future button can import
`setHeroCharactersEnabled` from `src/hero-characters.js`; no public toggle is
added yet. Enabled sessions retain the curved ground and lifecycle above.

Keep the illustrated composition; reduce ambient work instead of adding a
blocking loading screen. Topographic Flow presents a static rendered frame.
Orb and Chromatic Button animate during interaction only; constrained devices
use SVG/CSS alternatives. Loaded islands persist across viewport/visibility
changes, retaining their context and focus. Card loops run only on fine-pointer
hover or keyboard focus, and each card is observed separately. Native large
clouds and the repainting status pulse are static, hero labels drift once,
connection dashes play during hover/focus, and mobile header/sign/bar no longer
sample blurred backgrounds. The external
collector SVG retains its original self-contained animation and reduced-motion
handling; the parent viewport controller does not control that image document.

2026-10-26 detailed feedback revision:

Visual thesis: keep the illustrated cream/yellow poster and paper gallery,
with clear ink SVG marks and a light lavender/blue glass action color.
Content: poster → questions → source beams → evidence → principles → recent
repository activity → Agent/terminal installation → FAQ.
Interaction thesis: a genuinely centered Magic UI Dock, smooth card filtering,
finite source and border beams, one-time small-text entrances, bright ReactDrops
Chromatic actions, and a circular light/dark theme transition.

The four feature glyphs and glass box are replaced by a quiet SVG feature strip.
Chinese UI text now uses a self-hosted Noto Sans SC subset. Duplicate defensive
footnotes and the year-wide contribution surface are removed. Activity shows
real 30-day counts or explicitly weekly 90-day totals; it requests a cached
same-origin public GitHub endpoint. No authentication/account query is added.
The terminal switches between the exact Agent prompt and documented v0.7.1
wheel installation/setup commands. The action copies the currently selected
complete text even while the visual type-in is incomplete.

Magic UI source is pinned and MIT notices retained. The two Chromatic Buttons
share a palette and use an optional shader brightness floor; default zero
preserves the original material. The original gallery mouth path explicitly
has no fill, preventing the implicit black closing triangle.
